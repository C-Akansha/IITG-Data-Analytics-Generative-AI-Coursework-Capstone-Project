## 1. Program Overview

Welcome to my certification coursework repository! This repository showcases the modular projects and the final integrated capstone completed during the **Professional Certificate Program in Data Analytics and Generative AI** by Electronics & ICT Academy, IIT Guwahati (in collaboration with Simplilearn).

These projects represent a step-by-step learning progression, where each module focuses on mastering specific analytical tools, culminating in a final capstone where all methodologies are integrated. 

To provide a clear, executive-level view of my analytical methodologies, each folder within this repository contains:
- **Detailed Analytical Reports (PDF):** Comprehensive documentation of my workflow, data visualizations, and strategic business insights.
- **Verified Credentials:** The official module completion certificate for each respective project. 

*(Note: This repository is dedicated to executive summaries and analytical reports; raw source code and datasets are excluded.)*

## 3. Integrated Capstone: Healthcare Patient Readmission

The culminating project of this program is the [Healthcare Management Capstone](./Capstone_Healthcare_Management/), an end-to-end workflow analyzing 100,000+ patient records to predict 30-day hospital readmissions. 
* **Impact:** Identified the 70–80 age bracket and "super-utilizers" as the highest risk vectors, empowering healthcare management to deploy targeted resource allocation and cost reduction strategies.
* **Workflow Integrated:** Excel (Data Preparation) → SQL (Metric Extraction) → Python (EDA & Outlier Detection) → Tableau (Dashboarding).
