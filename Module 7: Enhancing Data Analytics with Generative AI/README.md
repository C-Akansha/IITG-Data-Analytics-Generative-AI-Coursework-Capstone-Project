# Module 7: Enhancing Data Analytics with Generative AI

### Coursework Project — IIT Guwahati Data Analytics Program

## 1. Module Overview

This module explores the integration of Generative AI (GenAI) into traditional data analytics workflows. Using prompt engineering techniques with large language models (LLMs), the project demonstrates how to accelerate exploratory data analysis (EDA), detect anomalies, generate executive-level data stories, and design a responsible enterprise AI adoption framework.

## 2. Project Breakdown

### Enhancing Analytics Processes with Generative AI (FutureTech Solutions)

Applied GenAI methodologies to an IoT smart device dataset (`iot_smart_device_data.csv`) to automate insights and establish operational governance.

* **GenAI-Assisted EDA & Quality Control:**

  * Configured LLM analyst personas via structured prompts to preview datasets, explain column semantics, and audit data completeness (verifying zero missing values).

  * Generated automated preprocessing and feature engineering plans for temporal (`Purchase_Date`) and categorical variables.

* **Trend & Anomaly Detection:**

  * Leveraged GenAI to uncover behavioral correlations (e.g., declining battery health leading to increased sensor alerts and maintenance costs).

  * Identified critical operational anomalies, such as high-alert counts occurring alongside good battery health, signaling potential sensor malfunctions.

* **Executive Storytelling & Visual Strategy:**

  * Translated technical statistics into concise, CXO-level business narratives using a problem-insight-action structure.

  * Formulated actionable recommendations for predictive maintenance and subscription optimization, paired with tailored BI visualization strategies.

* **Governance, Risks, and Phased Integration Framework:**

  * Analyzed enterprise challenges including data privacy risks, model hallucinations, and user adoption resistance.

  * Designed mitigation strategies such as Role-Based Access Controls (RBAC) and human-in-the-loop validation workflows.

  * Structured a 3-phase AI adoption framework (Assessment/Pilot, Limited Production, Full-Scale Adoption) alongside a task-allocation matrix separating GenAI automation tasks from human oversight.
